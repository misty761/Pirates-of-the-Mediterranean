Hi everyone.
<br><br>
I work at a factory during the day, and game development has been my dream project for a long time.

A few years ago, I tried making a 2D platformer game by myself because I was mostly interested in programming. But as a solo developer, I eventually realized my limits when it came to art, storytelling, animation, and all the other parts of game development. I ended up giving up on the project.

Recently, with the rapid progress of AI tools, I decided to challenge myself again and started making a visual novel.

Originally, I wanted to create a hybrid game — something like a visual novel mixed with a Vampire Survivors-style gameplay system. But after thinking realistically about the development time and scope, I changed my goal and decided to focus on simply finishing a visual novel first.

English is not my native language, so I relied heavily on ChatGPT while writing the script. If you notice awkward English or mistakes, I’d really appreciate your understanding. And if you point them out, I’ll do my best to fix them.

The same goes for programming. I’m self-taught, so there are probably many rough edges and mistakes in the code as well. Feedback is always welcome, and I’ll keep improving.

I’m sharing the source code publicly. Even if the project is imperfect, I hope it might help or encourage someone else who is learning game development on their own.

My biggest goal right now is simply to finish games and keep learning. But someday, if my situation allows it, I’d love to go back to my original idea and create something that combines visual novels with other gameplay genres — a bigger project that feels more like a “full game.”

Thanks for reading.
